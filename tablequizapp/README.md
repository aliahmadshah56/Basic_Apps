# Table Quiz App

A Flutter-based educational application designed to help users practice and master multiplication tables through an interactive quiz format.

## Features

- **Customizable Practice**: Select any multiplication table (1-12) for focused learning
- **Interactive Quiz**: 10 randomly generated questions per quiz session
- **Real-time Feedback**: Instant validation of answers with visual indicators
- **Score Tracking**: Final score display at the end of each quiz
- **User-Friendly Interface**: Clean, intuitive design optimized for learning
- **Responsive Design**: Works seamlessly on both mobile and tablet devices


## Installation

Follow these steps to set up and run the project:

1. **Prerequisites**
   - Flutter SDK (version 3.0 or higher)
   - Dart SDK (version 2.17 or higher)
   - Android Studio or VS Code with Flutter extension

2. **Clone the Repository**
   ```bash
   git clone https://github.com/aliahmadshah56/Basic_Apps.git
   cd Basic_Apps/tablequizapp
   ```

3. **Install Dependencies**
   ```bash
   flutter pub get
   ```

4. **Run the Application**
   ```bash
   flutter run
   ```

## Usage

1. Launch the application on your device or emulator
2. Enter the multiplication table number you wish to practice (1-12)
3. Tap the "Start Quiz" button to begin
4. For each question, enter your answer in the provided text field
5. Submit your answer to receive immediate feedback
6. Complete all 10 questions to see your final score
7. Return to the main screen to practice another table
